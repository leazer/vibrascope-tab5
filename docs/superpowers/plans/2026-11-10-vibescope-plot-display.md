# VibraScope 图表显示

- 主图横轴用整数 ms 或 Hz，波形和频谱纵轴按绝对值小于 1 显示三位，否则两位。瀑布图纵轴仍表示历史秒数。
- 在频谱设置中保存 0–3 个峰值标注的上限，默认 1。按可见曲线和当前视窗筛选局部峰，高于噪声底及邻域才标注。同频多轴合并，标注用整数 Hz，兼容线性与 dB。
- 在瀑布图设置中保存配色，默认原黄黑，新增蓝红热图和紫绿黄。切换颜色保留已有瀑布历史。
- 用主机回归验证噪声、同频合并、频段限制、旧配置兼容和停机重绘。构建 TAB5 与桌面，在模拟器核对刻度、峰标签及配色选项。
- 首轮实板运行触发 main 栈溢出。ELF 中绘图和峰标注自身栈帧分别为 1072 B 与 272 B，峰检测与 LVGL 调用还会继续加深调用栈。将 main 栈从 3584 B 调至 6144 B，复测三图采集与栈余量。
- TAB5 致命故障使用 ESP-IDF 的打印后停机模式。屏幕初始化后缓存 DPI 帧缓冲。在原生转储及看门狗关停之后，使用独立栈绘制停机原因、PC/RA/SP、异常编号与栈字。CPU 停止调度，只轮询液晶 DMA 以维持画面。LCD 或缓存不可用时走原生串口停机路径。
- 临时实板自检先采集，再触发一次受控异常。检查串口故障转储、液晶 DMA 刷帧标记及是否自动重启。自检结束后重刷正式应用。
