# TAB5 六面标定向导

- 入口在 VibraScope 的测量设置。每一面依次标定 ADXL357 和 ICM42688 加速度计，两颗都通过才前进。陀螺仪用于静止检测。
- 向导显示朝向、两颗加速度计及 ICM 陀螺仪的原始 XYZ 读数、到位状态和剩余时间。用板丝印位置辅助摆放，协议仍用传感器轴。
- 复用 VibraScope 的 USB worker 独占 ProbeClient。停止普通采集并排空，切 Slow 并维持 FETCH。两颗都拟合通过后读取候选记录，在原始读数下方显示两颗的 XYZ 偏置和比例系数，等待确认保存。退出时停止、清进度并恢复配置。
- 读记录命令返回 RAM 候选，取消后候选可能仍留在 RAM。分析只采用已保存的记录。向导拒绝把其他来源的未保存候选一并写入 Flash。
- 验证主机回归（朝向、稳定计时、丢数据、重试），编译桌面和 TAB5。模拟器以演示数据走向导。实机验证逐面、取消、USB 拔插及保存后重新上电。
